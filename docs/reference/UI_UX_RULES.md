## Mission-floor layout rules we apply

1. **One primary focus** — each Mission Demo step highlights exactly one zone.
2. **Labeled zones** — every region has a visible name so judges know where to look.
3. **Hierarchy by size/contrast/spacing** — not color alone (crew status also uses text + dot).
4. **Group related data** — crew together, vitals together, Earth link separate from local AI actions.
5. **Tabular numbers** — mono figures for HR/SpO₂/dose so columns stay readable.
6. **Charts** — legends + tooltips; never color-only meaning.
7. **Touch targets** — controls ≥ ~44px hit area, 8px+ gaps.
8. **Demo copy is directional** — say *what changed* and *where to look*, not marketing filler.
9. **Escape route** — Mission Demo always has Exit / Next.
10. **Reduced clutter** — floor view shows all critical numbers; deep tabs are secondary.
